Validation before promotion

The inference code now exists and 23 synthetic/reference unit tests pass, but the required competition rasters, frozen incumbent, and prior raw artifacts do not. No candidate has been run on official data or scored. Every promotion/download gate remains blocked.

Run status: not run. A script implementation is not evidence of a validated model. Do not upload, download, or use a competition slot based on an unrun candidate.

Frozen WPH-01 settings

  • Run separately on documented gravity and RTP magnetic input layers; do not invent a magnetic pseudogravity transform or field/magnetization assumptions.
  • Upward-continuation heights: 0, 100, 200, 400, 800, 1,600 and 3,200 m. Pick horizontal-gradient local maxima and track the longest consecutive pixel-scale path within a 2-pixel Chebyshev radius.
  • Compute H0 superlevel persistence on gradient-magnitude surfaces after Gaussian smoothing at 0.5, 1, 2, 4, 8, 16 and 32 pixels. Use a 4-neighbor graph, birth-minus-merge lifetime, omit one essential component per connected valid-mask component, and link maxima within 2 pixels across adjacent scales.
  • Multiply worm-survival fraction by normalized topological persistence for each layer. Robustly scale positive product values by their within-footprint 99.5th percentile and average gravity and magnetic scores equally. Scores are confidence/ranking values, not calibrated probabilities.
  • All settings and decision thresholds are in the machine-readable configuration. Any change after viewing holdout results is a new experiment and must be registered first.

Spatial holdout and promotion rule

  1. Use four contiguous equal pixel quadrants from the official sample footprint. Remove a 300 m (three-pixel) edge guard. Save per-fold mask hashes; never randomly split pixels.
  2. Compare the WPH candidate to the frozen current holdout incumbent on the same labeled valid pixels using the competition DTI (`alpha=0.2`, `beta=0.8`, triangular 300 m support).
  3. For the primary comparison, binarize both maps at matched support: the incumbent's positive-pixel count within each fold, with unit confidence for selected pixels. If the candidate has fewer positive cells than required, fail closed instead of adding arbitrary zeros.
  4. Also report unthresholded continuous-map DTI and the fixed 0.5% / 1% / 2% valid-fold-area support sweep. The 1× incumbent-support comparison is primary; sensitivity results do not replace the gate.
  5. Promote only if mean paired DTI delta is positive, at least three of four folds improve, and a 95% fold/block-bootstrap interval excludes zero. Keep all fold terms and the interval in the receipt.
  6. Report a single-scale gradient-magnitude comparator from the same data, plus nonzero-support fraction, top-1%/5% score-mass concentration and four-neighbor Moran's I. “Sparser and more concentrated” is a measured hypothesis.

Known-fault labels are incomplete and spatially biased; they can support a proxy comparison but cannot establish recall on genuinely unmapped faults.

Format and distinctness gates

  • Write one float32 GeoTIFF on the official sample raster's exact CRS, shape, transform, bounds and valid-data mask. Require finite in-footprint predictions in [0,1] and null/NaN outside. Reopen the written bytes and save the format receipt.
  • Compare raw prediction values with every prior raw output on the exact same valid footprint. Require absolute Pearson and Spearman below 0.90 for every artifact; report exact all-pixel Pearson, deterministic sampled Spearman, exact positive-support Jaccard and sampled top-1% rank overlap.
  • The Spearman statistic is computed on a deterministic systematic sample to bound memory; the report states the sample count/stride. Every prior must have a local readable TIFF and a matching SHA-256. Any missing/unchecked artifact blocks the audit.
  • A passing local receipt means eligible for human review only. A human entrant must arrange the authorized download location, verify the final package, choose whether to use a slot, and submit through the official portal.
