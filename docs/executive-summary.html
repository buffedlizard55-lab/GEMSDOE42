Before upload: verify the artifact

  1. Use an eligible, authorized candidate. It must have passed the frozen spatial-block holdout against the incumbent, with matched emitted mass and a recorded positive improvement; this repository does not yet have that evidence.
  2. Confirm distinctness. Compare raw output values with every prior TIFF on the common valid footprint. Record hashes, correlation statistics and support overlap. If any previous artifact is missing, the “every prior submission” check is incomplete.
  3. Open the format receipt. It must confirm one band, float32, CRS EPSG:32611, 100 m pixel size, exact template bounds/transform/shape, finite in-footprint values, no in-footprint nodata sentinel, and values within `[0,1]`.
  4. Check the outside footprint. Only outside-footprint cells may be null/NaN. The writer will preserve the template footprint and use NaN/nodata outside it, avoiding negative sentinel values that can trigger “Predicted values must be in range [0, 1]”.
  5. Keep the receipt with the file. Record the TIFF SHA-256, model/config ID, data checksums and holdout result before using a contest slot.

Click-by-click DrivenData submission

  1. Open the official GEMS competition page and sign into the participant's own account. This project will not ask for, store, or use account credentials.
  2. Open the submission form for the competition and select the validated .tif file from this project's download card. Do not select a GeoTIFF preview, zip with multiple rasters, training labels, or an unvalidated output.
  3. Enter a distinct submission name. Recommended pattern: GEMSDOE42-WPH01-YYYYMMDD-HHMMZ-<8-char-hash>. The actual generated name must be copied from its audit receipt; do not use the example literally.
  4. Paste the concise note shown with the candidate artifact. Keep it factual (method/config ID and gate status); do not describe an unscored candidate as a win.
  5. Submit in the authorized web form. Review the portal response, save the official submission ID/receipt and displayed public score, and separately mark whether it is the one final entry. Do not automate portal submission.
  6. Before the final deadline, choose exactly one final solution as required by the official rules. Feedback submissions are limited to three per week, so conserve slots and re-check the live rules/timeline before use.

Required by official rules

Generative-AI disclosure

The September 2026 DOE/NLR official rules allow generative AI but require the submission narrative to state the extent and manner in which it was used. The entrant is responsible for the accuracy, authenticity and authorship statements.

Draft wording to adapt truthfully: “Generative AI tools assisted with repository review, literature/source organization, and code drafting/review. The entrant reviewed and verified the data provenance, analysis, code, output raster and claims; any assistance used for the final narrative and submission materials is described here.”

Do not copy this statement unchanged if it does not accurately describe the final work. The human entrant must disclose all relevant AI use, including work on code, analyses and narrative.

Local workflow when authorized inputs are available

The repo includes a fail-closed preflight, candidate generator, format validator, four-fold holdout evaluator and all-prior audit. The template prior-manifest shipped here is incomplete and will correctly fail until every raw artifact and checksum is supplied.

python -m venv .venv
.venv/bin/python -m pip install -e '.[dev]'
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python scripts/prepare_data.py --data-dir data
.venv/bin/python scripts/build_candidate.py --data-dir data
.venv/bin/python scripts/evaluate_candidate.py \
  --candidate artifacts/candidates/<candidate-name>.tif \
  --incumbent data/holdout/incumbent-best.tif \
  --prior-manifest data/prior-output-manifest.csv \
  --data-dir data

The candidate generator writes only to ignored artifacts/candidates/. A passing local evaluation is still not an organizer score or a public download; a human entrant must review the evidence and choose any subsequent release or submission.
